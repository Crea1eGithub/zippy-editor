Hola, soy Zippy 👋

Notas de compatibilidad

shelve → localStorage

El módulo shelve de Skulpt no funciona de forma nativa (no hay sistema de archivos real en el navegador). Aquí se reemplaza por un módulo propio que guarda cada valor en window.localStorage del navegador, serializando con json. Funciona como un diccionario normal (shelf[clave] = valor, .get(), .keys()), pero los datos son persistentes solo en este navegador y este dominio: no se comparten entre dispositivos, y se pierden si el usuario borra los datos del sitio o navega en modo incógnito y cierra la ventana.

turtle: onkeypress / onkey

Un problema común de Skulpt es que los eventos de teclado del lienzo de la tortuga no llegan si el <canvas> no tiene el foco del navegador. Este programa le da tabindex al lienzo y lo enfoca automáticamente después de ejecutar; también se reenfoca si haces clic dentro del panel. Si aun así no responde, haz clic una vez dentro del panel de la tortuga antes de presionar teclas.

ZippyAssist y Groq

Zippy solo se activa si enciendes el interruptor y pegas tu propia clave de API de Groq. La clave se guarda únicamente en el localStorage de tu navegador y las peticiones se hacen directamente desde tu navegador a api.groq.com — este sitio no tiene servidor propio ni ve tu clave. Como cualquier clave usada en el navegador, cualquiera con acceso a tus herramientas de desarrollador podría leerla; no la uses en una máquina compartida.

Requisitos generales

  • Se necesita conexión a internet: Skulpt se carga desde un CDN, y Zippy llama a la API de Groq.
  • Si algo del CDN no carga (bloqueado por una red restrictiva, por ejemplo), el modo Python no funcionará, pero JavaScript y HTML sí, ya que corren nativamente en tu navegador.
